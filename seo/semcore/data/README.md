# Данные семантического ядра

- `seed-queries.txt` — что вбивать в Вордстат (генерится: `node seo/semcore/seed.js`).
- `wordstat-<дата>.txt` — **сюда кладёшь выгрузки**. Формат любой из привычных:
  `запрос<таб>частота`, `запрос;частота`, `запрос — частота`, CSV с шапкой.
  Файлов может быть сколько угодно, движок читает все сразу.
- `queries.json`, `core.json` — результат импорта, руками не правятся.

Порядок: `seed.js` → выгрузки в файлы → `import.js` → `plan.js`.
