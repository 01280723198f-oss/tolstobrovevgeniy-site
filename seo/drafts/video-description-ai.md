# Описание видео AI-ом: 30 секунд смотрел, 5 минут писал

Описание видео в YouTube или TikTok — часто такой же контент, как и сам ролик. Его видят в поиске, читают потом люди, которые уже посмотрели, ссылки оттуда лучше конвертируют, чем из комментариев. Писать руками — неэффективно. AI пишет за 5 минут, если дать ему нужные маркеры.

## Задача для AI в одну строку

Дашь AI видео → скажешь, что там происходит → AI напишет описание, которое:
- Складывается в нормальный текст (не просто список фактов)
- Включает ключевые слова (для поиска)
- Заканчивается CTA (call to action — призыв подписаться, перейти по ссылке)

## Способ 1: Через транскрипт (самый простой)

Если у тебя есть транскрипт видео (текст того, что говорится) — это 90% работы.

**Как получить транскрипт:**

1. **YouTube встроенный:** просмотренный видеоролик → три точки → «Открыть транскрипт» → копировать

2. **Локально (Whisper):**
```bash
# Установляешь Whisper (локальный распознаватель)
pip install openai-whisper

# Конвертируешь видео в аудио
ffmpeg -i видео.mp4 аудио.mp3

# Распознаёшь
whisper аудио.mp3 --language ru --output_format txt
```

**Потом промпт для Claude:**

```
Вот транскрипт видео:
[вставляешь транскрипт]

Напиши описание видео (200–300 слов) для YouTube:
- Первый абзац: о чём видео и почему смотреть
- Второй абзац: основные моменты (3–4 пункта)
- Третий абзац: где меня найти и что дальше

Ключевые слова: Claude Code, контент-завод, автоматизация
```

## Способ 2: Через анализ визуального контента (точнее, но медленнее)

Если видео визуальное (экран, кадры, рисунки) и в нём мало диалога — лучше описывать то, что видно.

**Шаг 1: Извлеки кадры из видео**

```bash
# Каждую 10-ю секунду
ffmpeg -i видео.mp4 -vf fps=0.1 кадр_%04d.jpg

# Или каждую секунду
ffmpeg -i видео.mp4 -vf fps=1 кадр_%04d.jpg
```

**Шаг 2: Дай кадры Claude с Vision**

```
Вот 30 кадров видео. Описание каждого [прикрепляешь]:
[кадр 1] → [краткое описание]
[кадр 2] → [краткое описание]
...

На основе этого напиши описание видео для YouTube (200–300 слов).
```

Claude возьмёт все кадры, увидит прогрессию и напишет связный текст.

## Способ 3: Автоматизация через скрипт

Если ты делаешь видео регулярно — скрипт сэкономит время.

**Python-скрипт для beschreibung видео:**

```python
#!/usr/bin/env python3
import subprocess
import json
import sys
import anthropic

def extract_transcript(video_path):
    """Извлечь транскрипт Whisper-ом"""
    audio_path = "/tmp/audio.mp3"
    # Конвертируешь видео в аудио
    subprocess.run(
        ["ffmpeg", "-i", video_path, "-q:a", "9", "-n", audio_path],
        capture_output=True
    )
    # Распознаёшь
    result = subprocess.run(
        ["whisper", audio_path, "--language", "ru", "--output_format", "json"],
        capture_output=True,
        text=True
    )
    data = json.loads(result.stdout)
    return data.get("text", "")

def write_video_description(transcript, keywords):
    """Генерируешь описание через Claude API"""
    client = anthropic.Anthropic()
    
    message = client.messages.create(
        model="claude-opus-5",
        max_tokens=1024,
        messages=[
            {
                "role": "user",
                "content": f"""Транскрипт видео:
{transcript}

Напиши описание для YouTube (200-300 слов):
- Первый абзац: о чём видео
- Второй: основные моменты
- Третий: CTA (подписаться/перейти по ссылке)

Ключевые слова: {', '.join(keywords)}

Начни прямо с текста, без вводных фраз."""
            }
        ]
    )
    return message.content[0].text

def main():
    if len(sys.argv) < 2:
        print("Использование: python script.py видео.mp4 --keywords слово1 слово2")
        sys.exit(1)
    
    video_path = sys.argv[1]
    keywords = sys.argv[3:] if "--keywords" in sys.argv else ["Claude", "контент"]
    
    print(f"📹 Читаю видео: {video_path}")
    transcript = extract_transcript(video_path)
    
    print(f"✍️  Пишу описание...")
    description = write_video_description(transcript, keywords)
    
    # Сохраняешь в файл
    output_file = video_path.replace(".mp4", "_description.txt")
    with open(output_file, "w") as f:
        f.write(description)
    
    print(f"✅ Готово: {output_file}")
    print(description)

if __name__ == "__main__":
    main()
```

Использование:

```bash
python write_description.py видео.mp4 --keywords Claude контент-завод
```

## Оптимизация описания под платформы

Каждая платформа показывает описание по-разному. Оптимизируй под каждую:

**YouTube:**
- Видит первые 100–150 символов (в листе видео)
- Дальше кнопка «Ещё»
- Рекомендует 200–5000 символов
- Поддерживает ссылки, хаштеги, временные метки

**TikTok:**
- Видит первые 35 символов
- Потом кнопка «Подробнее»
- Максимум 2200 символов
- Хаштеги работают, ссылки режут

**Instagram Reels:**
- Видит первые 125 символов
- Максимум 2200 символов
- Хаштеги обязательны (5–30 штук)
- Ссылки только в шапке профиля или Stories

**Пример для YouTube:**
```
Как за час написать статью на 3000 слов через Claude.
[125 символов — это видно без кнопки "Ещё"]

В видео я показываю:
• Промпт для анализа источников
• Структура статьи
• Как не переделывать потом
[дальше детали, ссылки, CTA]
```

## Как описание влияет на алгоритм

YouTube учитывает описание в четырёх местах:

1. **Поиск.** Ключевые слова из описания индексируются. Если видео про Claude Code, а описание про ChatGPT — поиск покажет его для ChatGPT, а не для Claude.

2. **Рекомендации.** Алгоритм смотрит, сколько людей кликают на ссылки из описания. Много кликов = видео релевантное = показывает чаще.

3. **CTR (Click-Through Rate).** Если описание интригующее, люди кликают в большей доле. YouTube видит высокий CTR и повышает видео в ленте.

4. **Время просмотра.** Если в описании есть таймкоды (00:00 Введение, 01:30 Суть), люди прыгают прямо к интересной части. Это влияет на время просмотра.

**На практике:** хорошее описание = на 15–25% больше кликов из поиска.

## Метрики для отслеживания

После загрузки видео, смотри в YouTube Studio:

- **CTR (процент кликов):** сколько % людей из найденных видео кликнули. Норма 3–5%, хорошо 7–10%.
- **Среднее время просмотра:** как долго смотрят. Если написал таймкоды — время вырастет.
- **Клики на ссылки из описания:** YouTube показывает в аналитике. Если много кликов — ссылку можно расширить.

**Сигнал для улучшения:** если CTR упал, переделай первое предложение описания. Если мало кликов на ссылку — переформулируй CTA.

## Часто спрашивают

**Насколько хорошо AI пишет описания?**
Зависит от материала. Если видео структурированное — хорошо на 80%. Если только визуальное — хуже. Всегда перечитай и добавь уникальных деталей.

**Может ли описание помочь с рейтингом видео?**
Да. YouTube смотрит ключевые слова, длину, клики на ссылки. Хорошее описание = 5–10% больше просмотров.

**Как часто обновлять описание?**
Один раз при заливке. Потом обновляешь, если сгорели ссылки или видео неожиданно залетело.

**Какой объём описания?**
- Минимум 100 слов (не спам)
- Оптимум 300–500 слов
- Максимум 1000 слов (для обучающих)

**Могу ли я использовать одно описание для TikTok и YouTube?**
Нет. TikTok показывает первые 35 символов, YouTube — 150. Пиши под платформу.

## Финальный чек перед публикацией

Перед тем, как нажимать кнопку опубликовать, проверь:

1. **Нет опечаток.** Перечитай дважды. YouTube не редактирует описание автоматически.
2. **Ссылки работают.** Кликни на каждую ссылку. Если одна мёртва — клики упадут.
3. **Таймкоды правильные.** Проверь, что 00:00 действительно момент из видео, а не где-то в конце.
4. **Хаштеги в конце.** Если это TikTok или Instagram — добавь хаштеги. YouTube их игнорирует, но не вредят.
5. **Первая строка интригует.** Помни, что YouTube показывает первые 100 символов. Они должны цеплять.

После публикации не забудь:
- Проверь, как выглядит описание на мобильнике (YouTube показывает по-разному)
- Мониторь клики на ссылки первую неделю
- Если кликов мало — переделай первое предложение и пересохрани описание
