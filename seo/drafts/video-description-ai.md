# Описание видео AI-ом: 30 секунд смотрел, 5 минут писал

Описание видео в YouTube или TikTok — часто такой же контент, как и сам ролик. Его видят в поиске, читают потом люди, которые уже посмотрели, ссылки оттуда лучше конвертируют, чем из комментариев. Писать руками — неэффективно. AI пишет за 5 минут, если дать ему нужные маркеры.

## Задача для AI в одну строку

Дашь AI видео → скажешь, что там происходит → AI напишет описание, которое:
- Складывается в нормальный текст (не просто список фактов)
- Включает ключевые слова (для поиска)
- Заканчивается CTA (call to action — призыв подписаться, перейти по ссылке)

## Способ 1: Через транскрипт (самый простой)

Если у тебя есть транскрипт видео (текст того, что говорится) — это 90% работы.

**Как получить транскрипт:**

1. **YouTube встроенный:** просмотренный видеоролик → три точки → «Открыть транскрипт» → копировать

2. **Локально (Whisper):**
```bash
# Установляешь Whisper (локальный распознаватель)
pip install openai-whisper

# Конвертируешь видео в аудио
ffmpeg -i видео.mp4 аудио.mp3

# Распознаёшь
whisper аудио.mp3 --language ru --output_format txt
```

**Потом промпт для Claude:**

```
Вот транскрипт видео:
[вставляешь транскрипт]

Напиши описание видео (200–300 слов) для YouTube:
- Первый абзац: о чём видео и почему смотреть
- Второй абзац: основные моменты (3–4 пункта)
- Третий абзац: где меня найти и что дальше

Ключевые слова: Claude Code, контент-завод, автоматизация
```

## Способ 2: Через анализ визуального контента (точнее, но медленнее)

Если видео визуальное (экран, кадры, рисунки) и в нём мало диалога — лучше описывать то, что видно.

**Шаг 1: Извлеки кадры из видео**

```bash
# Каждую 10-ю секунду
ffmpeg -i видео.mp4 -vf fps=0.1 кадр_%04d.jpg

# Или каждую секунду
ffmpeg -i видео.mp4 -vf fps=1 кадр_%04d.jpg
```

**Шаг 2: Дай кадры Claude с Vision**

```
Вот 30 кадров видео. Описание каждого [прикрепляешь]:
[кадр 1] → [краткое описание]
[кадр 2] → [краткое описание]
...

На основе этого напиши описание видео для YouTube (200–300 слов).
```

Claude возьмёт все кадры, увидит прогрессию и напишет связный текст.

## Способ 3: Автоматизация через скрипт

Если ты делаешь видео регулярно — скрипт сэкономит время.

**Python-скрипт для beschreibung видео:**

```python
#!/usr/bin/env python3
import subprocess
import json
import sys
import anthropic

def extract_transcript(video_path):
    """Извлечь транскрипт Whisper-ом"""
    audio_path = "/tmp/audio.mp3"
    # Конвертируешь видео в аудио
    subprocess.run(
        ["ffmpeg", "-i", video_path, "-q:a", "9", "-n", audio_path],
        capture_output=True
    )
    # Распознаёшь
    result = subprocess.run(
        ["whisper", audio_path, "--language", "ru", "--output_format", "json"],
        capture_output=True,
        text=True
    )
    data = json.loads(result.stdout)
    return data.get("text", "")

def write_video_description(transcript, keywords):
    """Генерируешь описание через Claude API"""
    client = anthropic.Anthropic()
    
    message = client.messages.create(
        model="claude-opus-5",
        max_tokens=1024,
        messages=[
            {
                "role": "user",
                "content": f"""Транскрипт видео:
{transcript}

Напиши описание для YouTube (200-300 слов):
- Первый абзац: о чём видео
- Второй: основные моменты
- Третий: CTA (подписаться/перейти по ссылке)

Ключевые слова: {', '.join(keywords)}

Начни прямо с текста, без вводных фраз."""
            }
        ]
    )
    return message.content[0].text

def main():
    if len(sys.argv) < 2:
        print("Использование: python script.py видео.mp4 --keywords слово1 слово2")
        sys.exit(1)
    
    video_path = sys.argv[1]
    keywords = sys.argv[3:] if "--keywords" in sys.argv else ["Claude", "контент"]
    
    print(f"📹 Читаю видео: {video_path}")
    transcript = extract_transcript(video_path)
    
    print(f"✍️  Пишу описание...")
    description = write_video_description(transcript, keywords)
    
    # Сохраняешь в файл
    output_file = video_path.replace(".mp4", "_description.txt")
    with open(output_file, "w") as f:
        f.write(description)
    
    print(f"✅ Готово: {output_file}")
    print(description)

if __name__ == "__main__":
    main()
```

Использование:

```bash
python write_description.py видео.mp4 --keywords Claude контент-завод
```

## Кейсы по типам видео

**Кейс 1: Обучающее видео (7–10 минут)**

Описание должно быть структурированным списком того, чему научат:

```
В этом видео я покажу:
⏰ 00:00 – Введение
⏰ 01:30 – Как установить Claude Code
⏰ 03:15 – Первый скрипт
⏰ 05:00 – Типичные ошибки
⏰ 07:30 – Как дебагить

Ключевые ссылки:
- Claude Code: https://...
- Документация: https://...
```

**Кейс 2: Обзорное видео (15–20 минут)**

Описание в форме проблема → решение → почему это важно:

```
Проблема: ручное написание контента занимает 3–4 часа на статью.

Решение: Claude Code + мой скилл `статья-воронка` пишут статью за 20 минут.

Почему это меняет экономику: вместо одного контент-менеджера — один инженер + автоматизация. Вместо $3K/месяц — $0 в переменных затратах.

В видео:
- Шаг за шагом повторяешь весь процесс
- Показываю, как подогнать под вашу нишу
- Считаю ROI
```

**Кейс 3: Новость/анонс (2–5 минут)**

Описание — это расширенная новость:

```
Claude выпустил Opus 5 с окном контекста в 200K токенов.

Это означает:
- Можешь положить целый проект в контекст
- Не нужно лазить по файлам
- Скорость обработки выросла на 3 раза

Цена прежняя: $20/месяц подписка или $0.003 за 1K токенов на API.

Что изменилось для контент-завода: кэшируются промпты, экономим 15% на API-расходах.
```

## Часто спрашивают

**Насколько хорошо AI пишет описания?**
Зависит от материала. Если видео структурированное (человек на камере, говорит чётко) — хорошо на 80%. Если визуальное (только экран, примелькивается) — хуже. Всегда перечитай и добавь два-три уникальных деталей.

**Может ли описание помочь с рейтингом видео?**
Да. YouTube смотрит:
- Ключевые слова в описании
- Длину описания (дольше → более информативно)
- Клики на ссылки из описания (CTR)

Поэтому хорошее описание = на 5–10% больше просмотров.

**Как часто обновлять описание?**
Один раз при заливке. Потом обновляешь только если:
- Ссылки сгорели
- Вышла новая версия той же версии
- Видео внезапно залетело (добавишь это в описание через неделю)

**Какой объём описания?**
- Минимум 100 слов (YouTube видит, что это не спам)
- Оптимум 300–500 слов (достаточно, чтобы рассказать суть, не скучно)
- Максимум 1000 слов (если это обучающее видео с деталями)

**Могу ли я использовать одно описание для TikTok и YouTube?**
Нет. TikTok ловит описание в первые 100 символов (первая строка), потом режет. YouTube показывает 150 символов, потом кнопка «Ещё». Пиши под платформу.
