# Плагины Claude Code: расширяй возможности своего боевого инструмента

Claude Code — это не просто интерфейс для Claude, это платформа, которую можно расширить. Плагины добавляют новые команды, интеграции с вашими сервисами, полностью меняют рабочий процесс. Разберу четыре типа плагинов и как их ставить.

## Что такое плагин в Claude Code

Плагин — это небольшая программа, которая:
1. Перехватывает команду (например, `/fetch` для загрузки данных с URL)
2. Передаёт эти данные в Claude
3. Показывает результат обратно в интерфейсе

Пример: официальный плагин `fetch` позволяет скачать содержимое веб-страницы и положить в контекст беседы, вместо того, чтобы копировать-вставлять вручную.

## Четыре типа плагинов

### Тип 1: Встроенные плагины (используй как есть)

Это плагины, которые идут вместе с Claude Code или устанавливаются одной командой.

**Примеры:**
- `fetch` — скачивает содержимое веб-страницы
- `grep` — поиск текста в файлах
- `shell` — выполнение bash-команд
- `read` — чтение файлов

Они уже активны, просто вводишь команду:

```
/fetch https://example.com
```

или через Bash:

```bash
grep -r "todo" ~/project/
```

### Тип 2: Плагины MCP (Model Context Protocol)

MCP — это стандарт для интеграции внешних сервисов. Через MCP ты подключаешь, например, Obsidian, Google Drive, свой API.

**Примеры MCP:**
- `obsidian` — доступ к заметкам в Obsidian
- `google-drive` — чтение/запись файлов в Google Drive
- `slack` — отправка сообщений в Slack
- `github` — интеграция с GitHub

**Как установить MCP-плагин:**

1. В Claude Code откроешь Settings (⚙️)
2. Ищешь раздел MCP или Integrations
3. Вводишь путь или URL MCP-сервера

Пример для Obsidian (если у тебя уже установлен):

```json
{
  "mcpServers": {
    "obsidian": {
      "command": "node",
      "args": ["~/.claude/mcp/obsidian.js"]
    }
  }
}
```

После этого в беседе станет доступна команда:

```
@obsidian search: мои заметки про Claude
```

### Тип 3: Скилы (Skills) — плагины под твою задачу

Скилы — это готовые сценарии для решения конкретных проблем. Они пишутся человеком и живут в репозитории.

**Примеры скилов:**
- `/сео` — генерирует статьи по SEO-ядру
- `/carousel` — создаёт карусель для Instagram
- `/postodel` — пишет посты для Telegram
- `/код-ревью` — проверяет код на ошибки

Скилы обычно ставятся командой:

```bash
claude skill install carousel
```

или скачиванием папки в `~/.claude/skills/`.

### Тип 4: Локальные скрипты (встраивай свою логику)

Если ты программист, можешь написать свой плагин, который запускается локально и получает доступ к файлам/API.

Простой пример плагина на Node.js (расширяет `/fetch`):

```javascript
// ~/.claude/plugins/my-fetch.js
module.exports = {
  name: 'my-fetch',
  command: 'fetch-cached',
  description: 'Fetch с кешем на день',
  async run(url) {
    const cache = require('fs').readFileSync('.cache.json');
    if (cache[url]) return cache[url];
    
    const response = await fetch(url);
    const content = await response.text();
    cache[url] = content;
    require('fs').writeFileSync('.cache.json', cache);
    return content;
  }
};
```

Потом можешь использовать как:

```
/fetch-cached https://example.com
```

## Кейс 1: Интеграция с Obsidian (заметки в контекст)

```bash
# 1. Установки MCP Obsidian
npm install -g @anthropic-ai/mcp-obsidian

# 2. Добавляешь в settings.json Claude Code
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["@anthropic-ai/mcp-obsidian"]
    }
  }
}

# 3. Перезагружаешь Claude Code

# 4. Теперь можно:
@obsidian search: методология контент-завода
```

Результат: Claude читает твою заметку из Obsidian и может помочь её расширить, переписать или соединить с другой заметкой.

## Кейс 2: Скилл для генерации кода (свой шаблон)

Если у тебя часто повторяется одно и то же — пишешь скилл:

```javascript
// ~/.claude/skills/my-component.js
module.exports = {
  name: 'my-component',
  trigger: '/component',
  description: 'Генерирует React-компонент с моим style guide',
  async run(componentName, props) {
    return `
import styles from './${componentName}.module.css';

export function ${componentName}(${props}) {
  return (
    <div className={styles.root}>
      {/* Твой шаблон */}
    </div>
  );
}`;
  }
};
```

## Кейс 3: MCP для своего API

Если у тебя есть свой бэкенд (например, сервис аналитики), можешь подключить его:

```json
{
  "mcpServers": {
    "my-api": {
      "command": "node",
      "args": ["./my-api-mcp.js"],
      "env": {
        "API_KEY": "твой-секретный-ключ"
      }
    }
  }
}
```

Дальше в Claude Code:

```
@my-api: покажи топ-10 страниц по трафику за сегодня
```

MCP-сервер достанет данные из твоего API и вернёт их Claude.

## Безопасность плагинов: чек-лист

Перед установкой плагина, пройди этот чек-лист:

1. **Чей плагин?** Официальный от Anthropic или community? Что говорит GitHub о авторе (кол-во звёзд, активность)?
2. **Что он делает?** Читай исходный код. Ищи подозрительные строки: `fetch`, `http.post`, `axios` — это звоночки, что плагин отправляет данные наружу.
3. **Какие разрешения нужны?** Если просит API-ключи — проверь, куда они идят. Если в `.env` локально — безопасно. Если отправляет на сервер — опасно.
4. **Последнее обновление.** Если плагин не обновлялся год — вероятно, не поддерживается.

**Красные флаги:**
- Просит пароль (плагин не должен)
- Отправляет данные на неизвестный сервер
- Требует администраторские права
- Нет лицензии (краденый код)

## Производительность: как не замедлить Claude Code

Каждый плагин добавляет время запуска:
- 1–3 плагина: не заметно
- 3–7 плагинов: +1–2 сек
- 7–10 плагинов: +3–5 сек
- 10+ плагинов: медленно

Удали неиспользуемые плагины, разделяй по профилям (работа/личное).

## Часто спрашивают

**Опасны ли сторонние плагины?**
Опасны, если ты не знаешь, что они делают. Читай исходный код перед установкой. Если плагин просит доступ к ключам API или к файлам — проверь, куда они идут. Официальные плагины от Anthropic — безопасны.

**Могу ли я отключить плагин?**
Да. В Settings найдёшь список активных плагинов — отключаешь тот, что не нужен. Или удаляешь строку из settings.json.

**Как написать свой плагин?**
Можно на Node.js, Python, Go — любой язык, который поддерживает stdio. Основная идея: плагин получает JSON на входе, возвращает JSON на выходе. Документация: https://github.com/anthropics/claude-code/blob/main/docs/PLUGINS.md

**Может ли плагин украсть мои данные?**
Если плагин отправляет данные на сторонний сервер — да. Поэтому проверяй исходный код. Локальные плагины (которые работают только на твоей машине) — безопасны.

**Сколько плагинов можно одновременно?**
Технически неограниченно, но каждый плагин замедляет запуск Claude Code на 0,5–1 секунду. Если их больше 10 — может быть заметно.

**Можно ли делать плагин для своей команды?**
Да, распространяй через GitHub или локально. Каждый член команды установит в свой Claude Code.
