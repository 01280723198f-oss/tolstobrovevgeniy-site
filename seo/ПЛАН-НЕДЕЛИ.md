## Процесс написания

```bash
# Каждая статья идёт через статья-воронка:
# 1. Кластер → брифан (ядро, интент, запросы)
# 2. Воронка: кодовое слово → лидмагнит → микро-продукт
# 3. Минут 15–20 на черновик в seo/drafts/
# 4. node seo/rewrite-guides.js slug
# 5. node seo/build.js && git push (1–2 минуты)
```

**Темпо:** 1 статья в день (раскидываем на неделю).  
**Не спешим:** качество > скорость, каждая статья может дать год трафика.
