В ролике я обещал два проекта и инструкцию, как переключать Claude Code туда и обратно. Всё ниже, по шагам. Сначала честно о том, что это такое, потому что в зарубежных роликах про «9 миллиардов бесплатных токенов» половину правды опускают.

Что это за два проекта

FreeLLMAPI и OmniRoute — открытые программы с GitHub, обе под лицензией MIT и бесплатные. Они делают одно и то же разными способами: собирают бесплатные тарифы десятков сервисов с нейросетями (Groq, Mistral, Gemini, DeepSeek и других) в одну точку подключения. Когда у одного сервиса кончается дневная квота, запрос сам уходит в следующий.

Claude Code умеет работать не только с Claude, а с любой моделью через такую точку. Поэтому когда твой лимит в Claude кончился, работа не встаёт: Claude Code продолжает отвечать, но уже другими моделями.

FreeLLMAPI OmniRoute
Звёзд на GitHub ~38 тыс. ~79 тыс.
Бесплатных токенов в месяц (оценка авторов) ~7,4 млрд ~1,62 млрд
Сколько сервисов 34 провайдера 375 провайдеров, 150+ с бесплатным тарифом
Как ставится приложение для Mac/Windows или Docker npm install -g omniroute
Фишка один ключ на всё, маршрутизатор сам выбирает модель сжатие запросов: 15–95% экономии токенов

Где здесь подвох

Цифры настоящие, но их легко понять не так. Четыре вещи, которые стоит знать до установки:

  1. Токены не дарит сам проект. Это сумма бесплатных тарифов сторонних сервисов. На каждом нужно зарегистрироваться и получить свой ключ. Подключил три сервиса — получил три квоты, а не все девять миллиардов.
  2. Модели не Claude. Claude Code продолжит работать, но думать будут Llama, Mistral, Gemini, DeepSeek. Для правок, черновиков и рутины их хватает. Сложную архитектуру лучше оставить Claude.
  3. «До 95% экономии» — это потолок. Авторы OmniRoute сами пишут: в среднем около 89% и только на подходящих задачах, где много повторяющегося текста.
  4. Россия. Часть сервисов (Google AI Studio, Groq и другие) из России без VPN не открывается, а где-то при регистрации просят зарубежный номер. FreeLLMAPI авторы прямо называют проектом для личных экспериментов, не для бизнеса на потоке.

Если после этого списка всё ещё интересно — значит, проект тебе подходит. Поехали.

Шаг 1. Поставить FreeLLMAPI

Самый простой путь — приложение. Зайди на страницу проекта на GitHub, раздел Releases, скачай .dmg для Mac или .exe для Windows и поставь как обычную программу. Аккаунт заводить не нужно.

Если на компьютере уже есть Docker, хватит одной команды в терминале:

curl -fsSL https://freellmapi.co/install.sh | bash

Дальше открой http://localhost:3001, зайди на страницу Keys и добавь ключи сервисов, которые ты получил. Там же, в шапке страницы, лежит твой единый ключ — он понадобится на шаге 3.

Шаг 2. Поставить OmniRoute

Нужен Node.js (программа для запуска JavaScript, ставится с nodejs.org за пару минут). Потом в терминале:

npm install -g omniroute
omniroute

Панель откроется на http://localhost:20128. Раздел Providers → выбираешь сервис → вставляешь его ключ. Если npm ругается на скрипты установки, в README проекта есть готовая команда с нужными разрешениями, её достаточно скопировать.

Какие сервисы подключить первыми

Не надо регистрироваться везде сразу. Для старта хватит двух-трёх:

  • Mistral — самая большая бесплатная квота в расчётах OmniRoute, около 1 млрд токенов.
  • Groq — очень быстрые ответы, хорошо для мелких правок.
  • Google AI Studio (Gemini) — сильные модели, но из России только через VPN.

Подключил, проверил, что отвечает, — дальше добавляешь по одному.

Шаг 3. Переключать Claude Code туда и обратно

Здесь главное, что я хотел показать. Оба проекта умеют запускать Claude Code только на один сеанс, ничего не меняя в твоих настройках:

npx freellmapi launch

или

omniroute run claude --model <модель из панели>

Закрыл это окно — и обычный claude снова работает на твоей подписке Claude, как раньше. Никакой путаницы: в одном окне Claude Code на бесплатных моделях добивает рутину, в другом твой Claude решает сложное.

Если хочешь, чтобы Claude Code ходил через FreeLLMAPI всегда, есть команда, которая сама пропишет настройки:

npx freellmapi setup-claude --url http://localhost:3001 --api-key <твой единый ключ>

Но я советую начать с разового запуска: так проще понять, где бесплатные модели справляются, а где нет.

Как я делю задачи

Сложное — новый проект, архитектура, разбор незнакомого кода — оставляю Claude. Простое — переименовать, поправить текст на странице, разобрать файл, написать черновик — отдаю бесплатным моделям. Лимит Claude перестаёт сгорать на мелочах и остаётся на главное.

Если пока выбираешь, какой Claude брать, загляни в разборы что даёт бесплатный Claude и Haiku 5.5 бесплатно, а про режимы работы есть статья моды Claude Code для эксперта.

Частые вопросы

Это законно и безопасно?

Оба проекта открытые, код можно прочитать. Ты пользуешься бесплатными тарифами сервисов по их же правилам. Ключи хранятся у тебя на компьютере в зашифрованном виде. Правила каждого сервиса стоит прочитать: OmniRoute помечает сервисы с рискованными условиями и не отправляет туда запросы автоматически.

Нужно ли уметь программировать?

Нет, но терминала не избежать: две-три команды из этой статьи нужно вставить и нажать Enter. Если страшно, начни с приложения FreeLLMAPI — там почти всё мышкой.

Будет ли так же умно, как Claude?

Нет. Бесплатные модели слабее на сложных задачах. Это способ не останавливаться, когда лимит кончился, а не замена Claude.

Сколько это стоит?

Сами проекты бесплатные. Платишь только за VPN, если нужны сервисы, закрытые для России.
