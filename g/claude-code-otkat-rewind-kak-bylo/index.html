В мультике заказчик сначала просит «сделай как у Apple», а через минуту пишет «а можно как было?». Знакомо каждому, кто собирает сайты на заказ. Если сайт делает Claude Code, вернуть прошлую версию можно за пару нажатий. Ниже по шагам: как это работает, как показать заказчику два варианта и где откат не спасёт.

Что такое откат в Claude Code

Claude Code сам запоминает состояние файлов перед каждым твоим сообщением. Это называется checkpoint, по-русски «контрольная точка». Ничего включать не нужно: точки создаются с первого запуска, хранятся вместе с разговором и доступны даже после того, как ты закрыл и снова открыл сессию.

В одной сессии Claude Code держит снимки последних 100 точек. Сами снимки по умолчанию живут около 30 дней, потом удаляются при очистке.

Как откатить сайт за две секунды

  1. Убедись, что поле ввода пустое.
  2. Дважды нажми Esc. Или напиши команду /rewind — откроется то же меню.
  3. В списке твоих сообщений выбери то, до которого нужно вернуться. Например, сообщение «сделай как у Apple».
  4. Выбери действие:
    • Restore code — вернуть только файлы, разговор оставить;
    • Restore conversation — вернуть только разговор, файлы не трогать;
    • Restore code and conversation — вернуть и то и другое.

Для истории с заказчиком подходит первый вариант: сайт возвращается к прошлой версии, а Claude помнит всё, что вы обсуждали, и не нужно объяснять заново.

Если в поле ввода есть текст, двойной Esc его очистит, а не откроет меню. Текст не пропадёт: стрелка вверх вернёт его из истории.

Как показать заказчику два варианта

Частая ситуация: заказчик сам не знает, что лучше, и хочет сравнить. Схема такая:

  1. Сделай первый вариант и сохрани скриншоты или ссылку на превью.
  2. Попроси Claude сделать второй вариант.
  3. Покажи оба. Если выбрали первый, откати код через /rewind к сообщению перед вторым вариантом.

Если вариантов будет много, удобнее ветки: команда /branch создаёт копию сессии, и можно пробовать другой путь, не трогая основной. Это уже для тех, кто работает с Claude Code регулярно.

Где откат не спасёт

Тут важно знать ограничения, чтобы не потерять работу:

  • Изменения через терминал. Если Claude удалял, переименовывал или копировал файлы командами (rm, mv, cp), откат их не вернёт. Он видит только правки, которые Claude делал своими инструментами редактирования.
  • Твои ручные правки. Если ты сам поправил файл в другом редакторе, откат этого не знает.
  • Помощники Claude. Правки, которые делали субагенты в фоне, часто не попадают в точки отката.
  • Ярлыки и ссылки на файлы. Файлы-ссылки (symlink) откат пропускает и честно пишет, сколько пропустил.

Чем откат лучше, чем «верни как было» в чате

Можно, конечно, просто написать Claude: «верни прошлую версию». Но тогда он будет переписывать файлы заново по памяти, и мелочи могут не совпасть: отступы, тексты, порядок блоков. Откат возвращает файлы ровно такими, какими они были, байт в байт, и не тратит лимит на переписывание.

Откат — не резервная копия

Сама Anthropic в справке пишет прямо: контрольные точки нужны для быстрого возврата внутри сессии, а для постоянной истории версий используй git. Для сайта на заказ это значит простое правило:

  • во время работы — откат через Esc Esc, быстро и без лишних шагов;
  • когда версия согласована — сохрани её в git или хотя бы сделай копию папки. Через месяц откат может уже не найти старые снимки.

Если git пугает, попроси Claude: «сохрани текущую версию сайта в git с понятным описанием». Он сделает всё сам, а тебе останется нажать подтверждение.

Как это выглядит в работе

Я держу такой порядок с любым сайтом: делаю правку → показываю → если не зашло, Esc Esc и назад → если зашло, сохраняю версию. Правки заказчика перестают пугать: любой эксперимент отменяется за пару секунд, и можно смело пробовать смелые варианты.

Если только начинаешь с Claude Code, загляни в статьи моды Claude Code для эксперта и что делать, если кончился лимит в Claude Code.

Частые вопросы

Нужно ли что-то настраивать?

Нет. Откат работает сразу. Настройка нужна, только если хочешь хранить снимки дольше 30 дней: для этого есть параметр cleanupPeriodDays.

Откат удалит мои сообщения Claude?

Только если выберешь вариант с разговором. «Restore code» возвращает файлы и оставляет переписку как есть.

Работает ли это в приложении, а не в терминале?

Команда /rewind есть в Claude Code. В обычном чате Claude на сайте такой кнопки нет: там правки делаются в разговоре.
