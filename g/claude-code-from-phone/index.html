В ролике я показал, как компьютер продолжает работать, пока я сижу на консультации. Здесь настройка по шагам: что нужно до старта, какая команда запускает сеанс и где эта схема ломается.

Что такое Remote Control и чем он не является

Remote Control это режим Claude Code, в котором твой локальный сеанс становится доступен с другого устройства: из приложения Claude на телефоне или из браузера на claude.ai/code.

Важное различие. Сеанс не уезжает в облако. Claude Code всё время работает на твоём компьютере, там же выполняются команды и лежат файлы. Телефон и браузер это окно в тот же процесс, а не вторая копия.

У Anthropic есть и облачный режим, Claude Code в веб-версии: он крутится на инфраструктуре Anthropic и удобен, когда репозиторий не склонирован локально и нужно запустить несколько задач сразу. Remote Control решает обратную задачу: ты уже работаешь на своей машине и хочешь продолжить с дивана.

Что нужно проверить до старта

Подписка. Режим доступен на планах Pro, Max, Team и Enterprise. Ключи API не подходят: если ты работаешь через свой ключ, Remote Control не включится.

Тарифы для команд. На Team и Enterprise владелец аккаунта сначала включает переключатель Remote Control в параметрах администратора Claude Code. Пока он выключен, у участников команда завершится ошибкой.

Вход. Запусти claude и войди через /login под аккаунтом claude.ai. Без подходящего аккаунта команда claude remote-control завершится с ошибкой.

Точка входа в API. Режим недоступен, если Claude Code ходит в Amazon Bedrock, Google Cloud Agent Platform или Microsoft Foundry, а также если переменная ANTHROPIC_BASE_URL смотрит на прокси или шлюз. Уберёшь переменную, и режим снова доступен.

Настройка за десять минут

Шаг 1. Открой папку проекта. Сеанс стартует в том каталоге, где ты работаешь, и видит его файлы.

Шаг 2. Запусти сервер.

claude remote-control

В первый раз Claude Code объяснит, что делает, и спросит Enable Remote Control? (y/n). Отвечаешь y, процесс остаётся жить в терминале и ждёт подключений.

Шаг 3. Возьми ссылку или QR-код. Терминал показывает URL сеанса. Нажми пробел, и рядом появится QR-код для телефона.

Шаг 4. Подключись. Открой ссылку в браузере, отсканируй QR-код камерой или найди сеанс по имени в приложении Claude: раздел Code в нижней навигации. Подключённые сеансы помечены значком компьютера с зелёной точкой.

Шаг 5. Продолжай задачу. Беседа синхронизируется в обе стороны. Можно писать из терминала, из браузера и с телефона по очереди, а подагенты и фоновые процессы видны с любого устройства.

Хочешь, чтобы режим включался сам при каждом запуске, запусти /config внутри Claude Code и поставь Enable Remote Control for all sessions в значение true.

Что можно делать с телефона

Полная локальная среда остаётся под рукой: файловая система, MCP-серверы, настройки проекта. Ввод @ подсказывает пути к файлам твоего проекта, как в терминале.

Фото и файлы отправляются прямо из приложения. Картинку Claude видит как часть сообщения, остальные файлы Claude Code скачивает на компьютер и передаёт ссылкой.

Push-уведомления приходят, когда длинная задача закончилась или нужно твоё решение. Включаются в /config после того, как ты разрешишь уведомления в системе телефона.

Где эта схема ломается

Компьютер должен быть включён, а процесс запущен. Закрыл терминал или вышел из VS Code, и сеанс уходит в офлайн, пока ты его не восстановишь. Если работаешь по SSH, запускай команду внутри tmux или screen.

Короткие обрывы переживаются сами. Ноутбук ушёл в сон, пропал вайфай: Claude Code переподключится, а сообщения, запросы разрешений и статусы встанут в очередь и придут после восстановления.

Долгие отказы сети. Если между тобой и серверами Anthropic что-то отвечает кодом 403, например после смены VPN, Claude Code три минуты пробует снова, а затем отключается и пишет, что именно отказало.

Один сеанс на процесс. Вне режима сервера каждый запуск Claude Code держит один удалённый сеанс. Несколько параллельных сеансов даёт режим сервера.

Нужна ли подписка для Remote Control?

Да. Режим работает на платных планах Pro, Max, Team и Enterprise и связан с аккаунтом claude.ai. Через ключ API он не включается, об этом Claude Code прямо пишет в ошибке.

Что будет, если закрыть терминал?

Сеанс перейдёт в офлайн, и на claude.ai и в приложении он покажется неактивным через несколько секунд. Работа не потеряется: сеанс можно возобновить, а на удалённой машине держать его в tmux.

Чем это отличается от Claude Code в облаке?

Местом выполнения. Remote Control работает на твоём компьютере с твоими файлами и настройками, облачный сеанс на инфраструктуре Anthropic без твоего локального окружения. Первый вариант для продолжения начатой работы, второй для задач с нуля.

Это безопасно для файлов?

Код и файлы не покидают компьютер, наружу идёт только беседа и статусы. Поэтому ограничения обычные: держи доступ к аккаунту у себя, а на командных тарифах смотри настройки доверенных устройств, которые включает администратор.

Зачем это эксперту, а не разработчику

Мой компьютер вечером делает посты, карусели и статьи по расписанию. Раньше, чтобы поправить задачу, я возвращался к столу. Теперь правлю с телефона между встречами: посмотрел, что получилось, попросил переделать заголовок, отправил дальше.
