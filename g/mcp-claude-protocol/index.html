MCP (Model Context Protocol) в Claude Code: полный гайд

Model Context Protocol (MCP) — это новый стандарт, как Claude напрямую подключается к твоей системе: БД, сервисам, приватным данным. Не через REST API обвязку. Прямо.

Что изменилось

До MCP (старый способ):

  1. Ты пишешь функцию, которая вызывает REST API
  2. Claude вызывает эту функцию
  3. Функция отправляет запрос в облако
  4. Ответ приходит назад
  5. Claude видит результат

Это работает, но:

  • Три слоя обвязки (функция → API → БД)
  • Каждый сервис — свой способ интеграции
  • Безопасность: тебе нужны API-ключи везде

После MCP (новый способ): Claude знает твою БД напрямую. Видит схему. Может писать SQL. Видит результат. Никакой промежуточной обвязки.

Как это работает технически

  1. MCP сервер — это программа на твоём компьютере или сервере, которая знает, как общаться с Claude
  2. Инструменты — что MCP сервер может делать (например, "выполнить SQL запрос")
  3. Claude видит инструменты и использует их, когда нужно

Пример:

Ты: "Сколько пользователей заказали за день?"

Claude видит инструмент "execute_sql"
Claude пишет: SELECT COUNT(*) FROM orders WHERE date > NOW() - INTERVAL 1 DAY
MCP сервер выполняет SQL
MCP возвращает: 1,243
Claude говорит: "За день заказало 1 243 пользователя"

Всё в одном процессе. Без API вызовов. Быстро.

Зачем это нужно

Скорость

REST API → сетевая задержка → ответ. MCP → выполнить локально → ответ моментально.

Безопасность

С REST API тебе нужны ключи везде. С MCP claude-code-setup/" class="ctx-link">Claude работает через единую точку входа.

Единство

Вместо "пять разных способов интегрировать Notion, GitHub, Slack, Google Docs" — один стандарт MCP.

Масштабируемость

Claude может работать с несколькими MCP серверами одновременно.

Практические примеры

Пример 1: вся информация про клиента в одном запросе

Ты даёшь Claude имя клиента.
Claude через MCP:
  - Смотрит в БД (таблица clients)
  - Смотрит в GitHub (его репо)
  - Смотрит в Google Docs (его документы)
  - Смотрит в Slack (его сообщения в приватном канале)

На выходе: полный профиль, собранный из пяти источников.

Как начать с MCP

Шаг 1: выбери, с чем интегрироваться

Популярные варианты:

  • Собственная БД (PostgreSQL, MySQL)
  • GitHub (читать репо, issue, pull requests)
  • Notion (читать/писать в БД)
  • Google Docs (читать документы)
  • Slack (читать каналы, отправлять сообщения)

Шаг 2: найди MCP сервер или напиши свой

Готовые серверы:

  • mcp-postgres — для PostgreSQL
  • mcp-notion — для Notion
  • mcp-github — для GitHub

Шаг 3: подключи к Claude Code

Две строки в конфиг → Claude видит инструменты → готово.

Главное: это сдвиг от "Claude вызывает функции" к "Claude это часть твоей системы".

Кодовое слово: MCP-CLAUDE
