7 новых правил для промптов Claude 5 от Anthropic

Anthropic раскрыла семь официальных правил для промптов Claude 5. Это не советы. Это изменения, которые меняют результат.

Если ты не переделал промпты под эти правила, результаты падают на 20–30%.

Правила

  1. Контекст ПЕРЕД примерами. Раньше можно было в любом порядке. Теперь порядок имеет значение.
  2. Структурированный вывод → точнее. Используй XML, JSON. Неструктурированный текст менее точен.
  3. Цепочка мыслей. Попроси Claude думать вслух, прежде чем отвечать.
  4. Ограничь длину вывода. Без лимита Claude пишет часами.
  5. Negative примеры работают лучше. Показывай, что делать НЕ нужно.
  6. Few-shot лучше zero-shot. Два-три примера вместо объяснения.
  7. Система промптов. Несколько маленьких промптов вместо одного большого.

Как это применять

Правильно:
Контекст → Примеры → Задача → Формат ответа (JSON) → Инструкции по длине

Неправильно:
Задача → Примеры → Контекст

Главное

Если твой промпт написан старым способом, обнови его. Результат будет заметно лучше.

Кодовое слово: PROMPT-RULES
